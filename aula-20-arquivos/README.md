# Aula 20 - Arquivos

   Como guardar informações num arquivo, pra não perder quando o programa fecha.

   - `open("nome.txt", "w")` abre (ou cria) um arquivo pra escrever.
   - `.write("texto")` escreve dentro do arquivo.
   - `open("nome.txt", "r")` abre o arquivo pra ler o que já tem escrito.
   - `.close()` fecha o arquivo, salvando as mudanças.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
