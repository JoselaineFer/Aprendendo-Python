# Aula 02 - Variáveis

   Aprendi que uma variável é uma "caixinha com nome" onde guardo uma informação.

   - `nome = "Josi"` guarda um texto.
   - `idade = 31` guarda um número.
   - Uso o nome da caixinha depois pra mostrar o que tem dentro, com `print()`.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
