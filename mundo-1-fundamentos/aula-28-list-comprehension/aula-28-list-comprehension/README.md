# Aula 28 - List comprehension

   Aprendi a criar uma lista nova a partir de outra, numa linha só.

   - `[expressao for item in lista]` cria uma lista nova aplicando uma expressão em cada item.
   - Dá pra adicionar um filtro com `if` no final, pra escolher só alguns itens.
   - `%` calcula o resto da divisão — usado aqui pra saber se um número é par.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
