# Aula 54 - Módulo os

   Aprendi a criar pastas e verificar arquivos usando o Python.

   - `os.makedirs("pasta", exist_ok=True)` cria uma pasta, sem dar erro se ela já existir.
   - `os.listdir(".")` lista tudo que tem na pasta atual.
   - `os.path.exists("caminho")` verifica se um arquivo ou pasta existe.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
