# Aula 17 - Loops aninhados

   Aprendi a colocar um loop dentro de outro loop.

   - Pra cada volta do loop de fora, o loop de dentro roda completo antes de voltar.
   - Útil pra montar tabelas e grades.
   - `f"Linha {linha}"` é uma f-string: coloca o valor de uma variável dentro de um texto.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
