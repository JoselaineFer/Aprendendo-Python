# Aula 06 - Laço while

   Aprendi a repetir um bloco de código enquanto uma condição for verdadeira.

   - `while condição:` repete o bloco de baixo enquanto a condição for verdadeira.
   - Preciso sempre atualizar a variável usada na condição (ex: `contador = contador + 1`), senão o programa repete pra sempre (loop infinito).

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
