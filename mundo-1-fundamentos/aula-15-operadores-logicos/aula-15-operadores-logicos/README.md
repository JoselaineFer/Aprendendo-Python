# Aula 15 - Operadores lógicos

   Aprendi a combinar várias condições numa regra só.

   - `and` exige que todas as condições sejam verdadeiras.
   - `or` basta que uma das condições seja verdadeira.
   - `not` inverte o valor (verdadeiro vira falso).

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
