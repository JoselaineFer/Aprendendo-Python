# Aula 73 - Menu interativo

   Aprendi a criar um menu que repete até o usuário escolher sair.

   - `while True:` mantém o menu aparecendo repetidamente.
   - `if/elif/else` decide qual ação tomar com base na escolha digitada.
   - `break` interrompe o loop na hora, saindo do menu.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
