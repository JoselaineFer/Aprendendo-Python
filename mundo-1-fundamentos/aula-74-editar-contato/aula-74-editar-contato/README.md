# Aula 74 - Editando um contato

   Aprendi a atualizar o dado de um item já existente numa lista de dicionários.

   - Busco o contato pelo nome, igual nas aulas de busca e remoção.
   - `contato["chave"] = novo_valor` substitui o valor daquela chave, sem recriar o dicionário.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
