# Aula 43 - Generators

   Aprendi que um generator entrega os valores um de cada vez, em vez de criar tudo de uma vez na memória.

   - `(expressao for item in lista)` com parênteses cria um generator, não uma lista.
   - Cada valor é calculado só na hora em que é pedido pelo loop.
   - Útil pra economizar memória quando há muitos dados.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
