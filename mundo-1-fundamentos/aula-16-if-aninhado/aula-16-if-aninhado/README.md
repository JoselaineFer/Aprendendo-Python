# Aula 16 - If aninhado

   Aprendi a verificar uma condição dentro de outra condição.

   - O `if` de dentro só é checado se o `if` de fora já foi verdadeiro.
   - A indentação (espaço na frente) organiza os "andares" da decisão.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
