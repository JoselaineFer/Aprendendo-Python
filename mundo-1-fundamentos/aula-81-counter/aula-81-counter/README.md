# Aula 81 - Counter

   Aprendi a contar quantas vezes cada valor aparece numa lista automaticamente.

   - `Counter(lista)` cria uma contagem de cada valor da lista.
   - Funciona como um dicionário: `contagem["valor"]` busca a quantidade.
   - `.most_common(n)` mostra os n valores mais frequentes.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
