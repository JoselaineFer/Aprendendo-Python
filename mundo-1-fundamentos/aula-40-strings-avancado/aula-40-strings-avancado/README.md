# Aula 40 - Strings avançado

   Aprendi mais truques com texto.

   - `texto[::-1]` inverte o texto, de trás pra frente.
   - `"palavra" in texto` verifica se uma palavra está dentro do texto.
   - `texto.find("palavra")` encontra a posição onde a palavra começa.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
