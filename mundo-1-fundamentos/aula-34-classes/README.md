# Aula 34 - Classes e objetos

   Aprendi os primeiros passos da programação orientada a objetos.

   - Uma classe é um "molde" pra criar objetos.
   - `__init__` roda automaticamente quando um objeto novo é criado, recebendo os dados iniciais.
   - `self` representa o próprio objeto que está sendo criado ou usado.
   - Cada objeto criado a partir da classe guarda seus próprios valores, independente dos outros.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
