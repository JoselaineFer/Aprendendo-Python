# Aula 13 - Tratamento de exceções

   Aprendi que try/except evita que o programa quebre quando algo dá errado.

   - `try:` tenta rodar o código de dentro.
   - `except:` roda se der algum erro no try, em vez de travar o programa.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
