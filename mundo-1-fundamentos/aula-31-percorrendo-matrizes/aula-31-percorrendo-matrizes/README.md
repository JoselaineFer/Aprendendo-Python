# Aula 31 - Percorrendo matrizes

   Aprendi a passar por cada posição de uma lista de listas usando dois loops.

   - O loop de fora percorre cada fileira.
   - O loop de dentro percorre cada posição dentro da fileira.
   - `print(valor, end=" ")` mostra na mesma linha em vez de pular pra próxima.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
