# Aula 70 - Projeto: agenda de contatos

   Primeiro projeto juntando várias coisas que aprendi: dicionários, listas, funções e loops.

   - Cada contato é um dicionário guardado dentro de uma lista.
   - `adicionar_contato()` cria e guarda um novo contato.
   - `listar_contatos()` percorre a lista e mostra cada um.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
