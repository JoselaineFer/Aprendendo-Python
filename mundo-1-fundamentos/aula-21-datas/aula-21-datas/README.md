# Aula 21 - Datas e horas

   Como pegar a data e hora atual no Python.

   - `from datetime import datetime` empresta a ferramenta de datas.
   - `datetime.now()` pega o dia e hora atuais do computador.
   - Dá pra pegar só uma parte, tipo `.year`, `.month`, `.weekday()`.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
