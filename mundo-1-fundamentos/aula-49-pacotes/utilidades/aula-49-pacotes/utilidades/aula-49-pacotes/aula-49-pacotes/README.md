# Aula 49 - Pacotes

    Aprendi a organizar módulos relacionados dentro de uma pasta (pacote).

    - Uma pasta com um arquivo `__init__.py` dentro vira um pacote de módulos.
    - `from pacote import modulo` importa um módulo específico do pacote.
    - Útil pra organizar projetos maiores, agrupando módulos parecidos.

    ## Como rodar
    No terminal, dentro desta pasta: `python main.py`
