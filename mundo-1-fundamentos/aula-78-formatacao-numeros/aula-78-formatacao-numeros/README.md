# Aula 78 - Formatação de números

   Aprendi a formatar números grandes e porcentagens de forma legível.

   - `{numero:,.2f}` adiciona separador de milhar e mantém 2 casas decimais.
   - `{numero:.1%}` transforma um decimal em porcentagem automaticamente.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
