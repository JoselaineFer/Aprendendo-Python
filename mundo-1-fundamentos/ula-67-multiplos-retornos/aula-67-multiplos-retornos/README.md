# Aula 67 - Múltiplos retornos

   Aprendi que uma função pode devolver vários valores de uma vez.

   - `return a, b, c` devolve os três valores juntos, empacotados numa tupla.
   - Ao chamar a função, posso "desempacotar" direto em variáveis separadas: `x, y, z = funcao()`.
   - `max()` e `min()` acham o maior e menor valor de uma lista automaticamente.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
