# Aula 19 - Random

  Como sortear números aleatórios usando o módulo random.

   - `import random` traz uma ferramenta pronta do Python pro meu programa.
   - `random.randint(1, 10)` sorteia um número inteiro entre 1 e 10, incluindo os dois extremos.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
