# Aula 56 - Threads

   Aprendi a rodar duas tarefas "ao mesmo tempo" usando threads.

   - `threading.Thread(target=funcao, args=(...))` prepara uma tarefa nova.
   - `.start()` inicia a tarefa sem esperar a anterior acabar.
   - `.join()` faz o programa esperar aquela tarefa terminar antes de seguir.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
