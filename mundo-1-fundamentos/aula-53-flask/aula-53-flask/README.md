# Aula 53 - Flask (criando um site simples)

   Aprendi a criar meu próprio site simples usando Flask.

   - `Flask(__name__)` cria a aplicação do site.
   - `@app.route("/caminho")` define uma "porta" do site e o que ela mostra.
   - `app.run(debug=True)` liga o site pra testar no navegador.
   - Precisa instalar antes: `pip install flask`

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`, depois abre `http://localhost:5000` no navegador.
