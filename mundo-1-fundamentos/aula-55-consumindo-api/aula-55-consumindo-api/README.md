# Aula 55 - Consumindo APIs

   Aprendi a buscar dados prontos de um serviço externo na internet.

   - `requests.get(url)` faz um pedido pra uma API (serviço que responde com dados).
   - `.json()` converte a resposta direto num dicionário Python.
   - Uso as chaves do dicionário (`dados["chave"]`) pra acessar os valores.
   - Precisa instalar antes: `pip install requests`

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
