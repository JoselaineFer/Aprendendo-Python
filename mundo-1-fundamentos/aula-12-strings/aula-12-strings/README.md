# Aula 12 - Strings

   Aprendi que strings têm métodos prontos pra transformar texto.

   - `.upper()` deixa tudo maiúsculo.
   - `.capitalize()` deixa só a primeira letra maiúscula.
   - `len(texto)` conta quantos caracteres tem.
   - `texto[0:4]` corta um pedaço do texto por posição.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
