# Aula 10 - Dicionários

   Aprendi que dicionário guarda pares chave-valor.

   - Cada item tem uma chave (nome) e um valor.
   - Busco um item pela chave, não pela posição, como numa agenda de contatos.
   - Dá pra adicionar uma nova chave com `dicionario["chave"] = valor`.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
