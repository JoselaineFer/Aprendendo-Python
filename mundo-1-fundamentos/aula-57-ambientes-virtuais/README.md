# Aula 57 - Ambientes virtuais (venv)

   Aprendi a criar uma "caixinha" isolada de ferramentas pra cada projeto Python.

   - `python -m venv nome_do_ambiente` cria o ambiente isolado.
   - Preciso "ativar" o ambiente antes de instalar ferramentas nele.
   - Isso evita conflito entre projetos que usam versões diferentes de uma mesma biblioteca.
