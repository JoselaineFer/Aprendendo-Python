# Aula 07 - Laço for

   Aprendi a repetir um bloco de código para cada item de uma lista, sem precisar de contador manual.

   - `for item in lista:` passa por cada item da lista, um de cada vez.
   - `range(1, 6)` gera números de 1 até 5 (o último número não entra).
   - Uma lista (`[...]`) guarda vários valores em uma única variável.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
