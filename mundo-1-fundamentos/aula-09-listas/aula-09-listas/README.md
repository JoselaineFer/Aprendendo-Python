# Aula 09 - Listas

   Aprendi a acessar e modificar itens de uma lista.

   - Listas começam a contar do zero: o primeiro item é `lista[0]`.
   - `.append(item)` adiciona um item no final da lista.
   - `.remove(item)` tira um item específico da lista.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
