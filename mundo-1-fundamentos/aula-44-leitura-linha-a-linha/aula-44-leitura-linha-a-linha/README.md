# Aula 44 - Leitura linha a linha

   Aprendi a ler um arquivo linha por linha, em vez de tudo de uma vez.

   - `for linha in arquivo:` percorre o arquivo uma linha de cada vez.
   - `.strip()` remove espaços e quebras de linha extras do texto lido.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
