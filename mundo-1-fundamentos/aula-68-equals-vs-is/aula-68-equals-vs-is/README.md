# Aula 68 - == vs is

   Aprendi a diferença entre comparar valores e comparar identidade.

   - `==` verifica se o conteúdo de duas variáveis é igual.
   - `is` verifica se duas variáveis apontam pra exatamente o mesmo objeto na memória.
   - Duas listas com o mesmo conteúdo podem ser `==` mas não `is`, se forem criadas separadamente.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
