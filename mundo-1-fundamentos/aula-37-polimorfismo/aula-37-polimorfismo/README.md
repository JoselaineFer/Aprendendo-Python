# Aula 37 - Polimorfismo

   Aprendi a chamar a mesma função em objetos de classes diferentes, cada um respondendo do seu jeito.

   - Classes diferentes podem ter uma função com o mesmo nome.
   - Ao percorrer uma lista de objetos variados, chamo a mesma função sem precisar saber de qual classe é cada um.
   - Cada objeto executa seu próprio comportamento pra essa função.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
