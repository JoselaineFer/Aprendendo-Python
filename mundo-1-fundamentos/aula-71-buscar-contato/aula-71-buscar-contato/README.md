# Aula 71 - Buscando um contato

   Aprendi a procurar um item específico dentro de uma lista de dicionários.

   - Percorro a lista comparando cada nome com o nome procurado.
   - `.lower()` evita erro de comparação por causa de maiúscula/minúscula.
   - `return` dentro do loop já devolve e para a função assim que encontra.
   - `None` representa "nada encontrado"; um `if` consegue diferenciar isso automaticamente.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
