# Aula 32 - Lista de dicionários

   Aprendi a guardar várias "fichas" (dicionários) dentro de uma única lista.

   - Cada item da lista é um dicionário com suas próprias chaves e valores.
   - `lista[0]["chave"]` acessa um valor específico dentro do primeiro item.
   - Um `for` percorre cada dicionário da lista, permitindo usar suas chaves normalmente.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
