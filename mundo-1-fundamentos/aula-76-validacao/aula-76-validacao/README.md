# Aula 76 - Validação de dados

   Aprendi a checar se uma entrada do usuário é válida antes de usar.

   - `.isdigit()` verifica se um texto é composto só de números.
   - Combino validações com `and` pra checar se o número está num intervalo aceitável.
   - Um `while True` com `return` dentro repete até receber uma resposta válida.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
