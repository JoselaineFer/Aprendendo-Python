# Aula 41 - enumerate()

   Aprendi a pegar a posição e o valor de cada item de uma lista ao mesmo tempo.

   - `enumerate(lista)` entrega pares de (posição, item) a cada volta do loop.
   - Substitui a necessidade de criar um contador manual pra saber a posição.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
