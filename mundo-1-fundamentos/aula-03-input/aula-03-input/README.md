# Aula 03 - input()

   Aprendi que `input()` faz o programa perguntar algo e esperar a resposta da pessoa.

   - O texto dentro do `input("...")` é a pergunta mostrada na tela.
   - O que a pessoa digita fica guardado numa variável.
   - Tudo que vem do `input()` é sempre texto, mesmo que pareça um número.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
