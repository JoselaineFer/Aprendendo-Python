# Aula 38 - Exceções específicas

   Aprendi a tratar tipos diferentes de erro com mensagens diferentes.

   - `except ValueError:` trata erro de valor inválido, tipo texto onde esperava número.
   - `except ZeroDivisionError:` trata erro de divisão por zero.
   - O Python identifica o tipo do erro e escolhe o except certo pra ele.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
