# Aula 11 - Tuplas

   Aprendi que tupla é uma lista que não pode ser alterada depois de criada.

   - Usa parênteses `(...)` em vez de colchetes `[...]`.
   - Acesso os itens do mesmo jeito que numa lista (`tupla[0]`).
   - Uso quando quero garantir que os dados não mudem, tipo dias da semana.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
