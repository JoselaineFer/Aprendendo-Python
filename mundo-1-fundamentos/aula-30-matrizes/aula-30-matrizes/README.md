# Aula 30 - Matrizes (listas de listas)

   Aprendi a guardar uma lista dentro de outra lista, formando uma espécie de tabuleiro.

   - `tabuleiro[0]` pega a primeira lista inteira (fileira).
   - `tabuleiro[0][1]` pega o item na posição 1 dentro da primeira fileira.
   - Um `for` simples percorre cada fileira por vez.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
