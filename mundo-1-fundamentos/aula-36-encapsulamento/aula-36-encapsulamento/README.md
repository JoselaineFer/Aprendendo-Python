# Aula 36 - Encapsulamento

   Aprendi a proteger os dados de um objeto, controlando como eles são acessados.

   - `self.__saldo` (com dois underlines) esconde o dado, impedindo acesso direto de fora.
   - Crio funções específicas (como `depositar` e `ver_saldo`) pra mexer no dado com segurança.
   - Isso evita que o valor seja alterado de forma descontrolada.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
