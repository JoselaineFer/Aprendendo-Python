# Aula 48 - Property (getters e setters)

   Aprendi a criar uma "porta de leitura e escrita" pra um dado protegido.

   - `@property` deixa acessar um valor como se fosse uma variável comum, sem parênteses.
   - `@nome.setter` cria a função que roda quando tento alterar esse valor, podendo validar antes.
   - Isso combina a proteção da Aula 36 com uma forma mais simples de usar.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
