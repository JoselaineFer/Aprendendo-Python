# Aula 45 - CSV

   Aprendi a escrever e ler arquivos no formato CSV (tabela em texto).

   - `csv.writer(arquivo)` cria um escritor pra montar linhas de tabela.
   - `.writerow([...])` escreve uma linha, cada item virando uma coluna.
   - `csv.reader(arquivo)` lê o arquivo e devolve cada linha já separada em colunas.
   - `with open(...) as arquivo:` fecha o arquivo automaticamente no final.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
