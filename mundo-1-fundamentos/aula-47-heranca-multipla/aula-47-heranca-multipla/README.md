# Aula 47 - Herança múltipla

   Aprendi que uma classe pode herdar de mais de um molde ao mesmo tempo.

   - `class Filha(Mae1, Mae2):` herda funções das duas classes.
   - `pass` é usado quando a classe não precisa adicionar nada extra.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
