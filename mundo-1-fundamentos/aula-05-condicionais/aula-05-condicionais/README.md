# Aula 05 - Condicionais (if/else)

   Aprendi a fazer o programa escolher um caminho dependendo de uma condição.

   - `if condição:` roda o bloco de baixo SE a condição for verdadeira.
   - `else:` roda o bloco de baixo quando a condição é falsa.
   - Usei `int()` pra transformar o texto do input em número, pra dar pra comparar com `>=`.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
