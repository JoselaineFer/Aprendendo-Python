# Aula 22 - Módulo math

   Aprendi a usar a ferramenta math pra contas mais avançadas.

   - `import math` empresta a caixinha de ferramentas matemáticas.
   - `math.sqrt(numero)` calcula a raiz quadrada.
   - `math.ceil()` arredonda pra cima; `math.floor()` arredonda pra baixo.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
