# Aula 61 - Docstrings e comentários

   Aprendi a documentar meu código pra facilitar o entendimento futuro.

   - Docstring (`"""texto"""`) logo abaixo do `def` explica o que a função faz.
   - Comentários (`# texto`) explicam trechos específicos do código e são ignorados pelo Python.
   - `sum(lista)` soma todos os itens; `len(lista)` conta quantos itens tem.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
