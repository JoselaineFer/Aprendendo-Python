# Aula 58 - requirements.txt

   Aprendi a listar e reinstalar as dependências de um projeto.

   - `pip freeze > requirements.txt` salva a lista de bibliotecas instaladas e suas versões num arquivo.
   - `pip install -r requirements.txt` instala tudo dessa lista de uma vez, útil em outro computador.

   ## Exemplo de requirements.txt
```
   requests==2.31.0
   flask==3.0.0
```
