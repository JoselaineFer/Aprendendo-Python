# Aula 80 - Deque (filas)

   Aprendi a usar uma estrutura própria pra filas, mais rápida que listas comuns.

   - `deque()` cria uma fila vazia.
   - `.append(item)` adiciona no final da fila.
   - `.popleft()` remove e devolve quem está na frente da fila.
   - Segue a regra FIFO: quem entra primeiro, sai primeiro.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
