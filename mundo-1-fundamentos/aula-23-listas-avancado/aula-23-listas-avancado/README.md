# Aula 23 - Listas (métodos avançados)

   Aprendi mais alguns truques pra mexer em listas.

   - `.sort()` coloca a lista em ordem crescente.
   - `.reverse()` inverte a ordem da lista.
   - `.count(valor)` conta quantas vezes um valor aparece na lista.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
