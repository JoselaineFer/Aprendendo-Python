# Aula 46 - Decoradores

   Aprendi a adicionar comportamento extra a uma função sem mudar o código de dentro dela.

   - Um decorador é uma função que recebe outra função e devolve uma versão "embrulhada".
   - `@nome_do_decorador` em cima de uma função aplica esse embrulho automaticamente.
   - Útil pra adicionar algo antes/depois de várias funções, sem repetir código.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
