# Aula 29 - Conjuntos (set)

   Aprendi que um conjunto (set) guarda valores sem repetição.

   - Mesmo colocando um valor repetido, ele só aparece uma vez no conjunto.
   - `.add(valor)` adiciona um item novo.
   - `valor in conjunto` verifica se um valor está presente, devolvendo True ou False.
   - Não tem posição numerada como a lista, então não dá pra acessar por `[0]`.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
