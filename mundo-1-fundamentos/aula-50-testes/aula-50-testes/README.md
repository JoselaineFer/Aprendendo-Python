# Aula 50 - Testes automatizados

   Aprendi a verificar automaticamente se meu código funciona como esperado.

   - `assert condicao` checa se algo é verdadeiro; se for falso, o programa avisa um erro.
   - Testar uma função com vários casos diferentes dá mais confiança de que ela está correta.
   - Rodar os testes de novo depois de mudar o código ajuda a pegar erros rapidamente.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
