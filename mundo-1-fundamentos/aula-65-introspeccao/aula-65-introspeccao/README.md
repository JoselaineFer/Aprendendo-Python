# Aula 65 - Introspecção

   Aprendi a perguntar pro Python o tipo de uma variável.

   - `type(variavel)` mostra qual é o tipo de dado (int, str, list, etc).
   - `isinstance(variavel, tipo)` verifica se a variável é de um tipo específico, respondendo True ou False.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
