# Aula 35 - Herança

   Aprendi a criar uma classe que aproveita o que já existe em outra classe.

   - `class Filha(Mae):` faz a classe Filha herdar tudo da classe Mae.
   - A classe filha recebe automaticamente o `__init__` da classe mãe.
   - Posso "sobrescrever" uma função herdada, dando um comportamento próprio pra ela.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
