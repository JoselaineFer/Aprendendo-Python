# Aula 25 - Valor padrão em funções

   Aprendi que um parâmetro pode ter um valor padrão, usado quando não informo nada.

   - `def funcao(param="valor"):` define o valor que será usado se ninguém passar outro.
   - Ao chamar a função sem esse argumento, ela usa o padrão automaticamente.
   - Se eu informar um valor na chamada, ele substitui o padrão.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
