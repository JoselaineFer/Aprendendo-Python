# Aula 33 - map() e filter()

   Aprendi a aplicar uma função em cada item de uma lista, ou filtrar itens por uma regra.

   - `lambda n: n * 2` é uma função rápida, sem nome, pra contas simples.
   - `map(funcao, lista)` aplica a função em todos os itens da lista.
   - `filter(funcao, lista)` mantém só os itens onde a função devolve verdadeiro.
   - Envolvo com `list(...)` pra transformar o resultado numa lista de verdade.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
