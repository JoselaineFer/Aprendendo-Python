# Aula 69 - Operador ternário

   Aprendi a escrever um if/else simples numa única linha.

   - `valor_a if condicao else valor_b` escolhe entre dois valores, dependendo da condição.
   - É a mesma lógica do if/else tradicional, só que mais resumida.
   - Bom pra decisões simples; para lógicas complexas, o if/else tradicional é mais legível.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
