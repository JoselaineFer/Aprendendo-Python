# Aula 75 - Salvando a agenda em JSON

   Aprendi a guardar a lista de contatos num arquivo, pra não perder ao fechar o programa.

   - `json.dump(dados, arquivo)` escreve os dados direto no arquivo em formato JSON.
   - `json.load(arquivo)` lê o arquivo e devolve os dados prontos pra usar.
   - Assim a agenda continua existindo mesmo depois de fechar e abrir o programa de novo.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
