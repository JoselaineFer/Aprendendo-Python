# Aula 66 - Constantes

   Aprendi a usar constantes pra valores que não devem mudar durante o programa.

   - Constantes são escritas em MAIÚSCULO por convenção (o Python não impede alteração, mas avisa a intenção).
   - Colocar valores importantes no topo do arquivo facilita encontrar e ajustar depois.
   - Evita "números mágicos" soltos no meio do código sem explicação.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
