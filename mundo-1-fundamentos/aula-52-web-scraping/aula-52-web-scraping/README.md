# Aula 52 - Web scraping básico

   Aprendi a buscar informações de uma página da internet automaticamente.

   - `requests.get(url)` visita um site e traz o conteúdo (HTML) dele.
   - `BeautifulSoup` organiza esse HTML pra facilitar a busca por partes específicas.
   - `.find("tag")` procura uma tag específica dentro do HTML; `.text` pega só o texto de dentro.
   - Precisa instalar bibliotecas extras: `pip install requests beautifulsoup4`

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
