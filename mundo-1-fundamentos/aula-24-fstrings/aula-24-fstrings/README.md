# Aula 24 - F-strings avançadas

   Aprendi a formatar melhor o texto que mostro na tela.

   - `f"texto {variavel}"` insere o valor de uma variável dentro do texto.
   - `{numero:.2f}` mostra o número sempre com 2 casas decimais, tipo valores em dinheiro.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
