# Aula 14 - Return

   Aprendi que return faz a função devolver um valor, em vez de só mostrar na tela.

   - `return a + b` calcula e devolve o resultado.
   - Posso guardar esse valor numa variável (`resultado = somar(5, 3)`) e usar depois.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
