# Aula 08 - Funções

   Aprendi a criar um pedaço de código reutilizável, que posso chamar quantas vezes quiser.

   - `def nome_da_funcao(parametro):` cria a função.
   - O parâmetro é uma informação que a função recebe pra usar por dentro.
   - Chamo a função escrevendo o nome dela seguido de `()`, passando o valor que quero usar.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
