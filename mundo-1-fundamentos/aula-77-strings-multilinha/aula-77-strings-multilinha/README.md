# Aula 77 - Strings multi-linha

   Aprendi a criar um texto com várias linhas guardado numa única variável.

   - Três aspas `"""..."""` permitem texto com quebras de linha preservadas.
   - Combinado com f-string, dá pra montar modelos de texto (recibos, emails) com partes variáveis.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
