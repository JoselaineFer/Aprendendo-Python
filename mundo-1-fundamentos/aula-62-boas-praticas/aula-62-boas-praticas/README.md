# Aula 62 - Boas práticas de nomeação

   Aprendi a dar nomes claros pra variáveis e funções.

   - Nomes de funções geralmente são verbos (ex: calcular_area_retangulo).
   - Nomes de variáveis geralmente são substantivos (ex: largura, altura, area).
   - Padrão do Python: minúsculo com underline separando palavras (snake_case).

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
