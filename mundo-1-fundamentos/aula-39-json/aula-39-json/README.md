# Aula 39 - JSON

   Aprendi a converter dados do Python pra um formato de texto universal (JSON) e de volta.

   - `json.dumps(dicionario)` converte um dicionário Python em texto JSON.
   - `json.loads(texto)` converte um texto JSON de volta em dicionário Python.
   - JSON é usado pra salvar dados em arquivo ou trocar informações entre programas diferentes.

   ## Como rodar
   No terminal, dentro desta pasta: `python main.py`
